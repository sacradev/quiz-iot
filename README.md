# 📡 Quiz IoT

Quiz de fixação desenvolvido como ferramenta de estudo para a 
disciplina de Fundamentos da Eletrônica — curso Técnico em 
Desenvolvimento de Sistemas, SENAI.

## Como funciona

Questões de múltipla escolha apresentadas em looping infinito 
e ordem aleatória. O sistema registra acertos e erros ao longo 
da sessão.

## Origem

Criado por necessidade real: sem tempo para estudar antes da 
prova, desenvolvi essa ferramenta para fixar o conteúdo de 
forma ativa. Foi o ponto de partida para o 
[Algoritmo Quest](https://github.com/sacradev/algoritmo-quest) 
— uma versão muito mais elaborada da mesma ideia.

## Tecnologias

- HTML5
- JavaScript puro
